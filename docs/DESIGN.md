# Aptmark design direction
Primary job: help a student choose a focused next activity, then get out of the way of the question.
Palette: paper #f7f9f8, surface #ffffff, ink #22342e, subdued #697770, rule #e1e7e3, forest #245c45. The brief explicitly requests a light neutral and a single accent. Avoid cream/terracotta, gradients, generic marketing metrics, or fictional student history.
Typography: system humanist sans for navigation and forms; Georgia for a small number of academic display headings and passage reading. Tabular numerals for timers.
Layout: 232px quiet left navigation; 1100px maximum content; asymmetric 2:1 workspace with an agenda column, not a field of equal cards. A single original coordinate-plot illustration serves the welcome panel; all plotted values have real mathematical meaning.
Dashboard: heading → next-action study panel → subject practice entries → evidence/skill coverage → recent activity. Cold start says “Not enough evidence,” not a fictional predicted score.
Practice: narrow controls; passage/question split; answer choices use large keyboard-friendly targets; a post-submit explanation occupies the lower question pane. A visible candidate-preview notice prevents confusing unreleased content with approved inventory.
Review: restrained borders, no shadows except floating dialogs, compact 8/12/16/24/32/48 spacing, 6–12px radii according to hierarchy. Use icons only for navigation, question tools, and status.
