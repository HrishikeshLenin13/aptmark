# Roadmap and acceptance gates
A — Foundation: official specification and taxonomy researched; local tooling implemented. Cloud integrations are not configured.
B — Content foundation: 42 Math families + 33 Reading/Writing families, 5,405 candidates across all 30 official skills. Structural and mathematical checks do not confer human approval. Expand independently authored families and difficult reading content, acquire actual editorial review, and publish staged releases (pilot → 500 → 2,000 → 5,000 → 10,000). Track numerical variants separately from families. Never fill an inventory target by publishing unchecked templates.
C — Practice pilot: local guest/email-password accounts, server grading, drafts, bookmarks, explanations, reports, history. Hosted authentication, recovery, verified email, cross-device cloud sync, and production consent remain.
D — Adaptive baseline: deterministic Bayesian evidence, uncertainty, exposure avoidance, family diversity, review scheduling, recommendations, planner and analytics. Need chronological real-data evaluation, calibrated Rasch fitting, prerequisite remediation efficacy, and outcome studies.
E — Assessments: tested timing/locking/break state machine, short diagnostic, Math preview. Need calibrated approved full-length forms, blueprint-constrained pool assembly, exposure controls, and validated route selection. No predicted SAT score until empirical support exists.
F — Tutor: working no-cost static grounded guidance. Add a server-only provider abstraction, usage budget, caching/coalescing, retrieval, grounding checks and graceful provider outage handling before advertising AI tutoring.
G — Design: responsive original application, actual empty states, passage/math/table/figure rendering, restrained analytics. Iterate after browser and accessibility results. Add selective persisted highlighting, full exam option eliminator, richer line reader and keyboard shortcut documentation.
H — Launch: cloud adapter/migrations, RLS integration tests, editorial signoff, independent security/accessibility/privacy reviews, minors/consent/retention flows, reproducible cloud deployment, backup recovery, calibrated content and appropriate operating budget. No public deployment has been requested or performed.
