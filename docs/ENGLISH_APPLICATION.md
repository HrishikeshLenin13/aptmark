# English application families

A finite, independently authored batch adds **44 Reading and Writing candidates**: four contexts in each of eleven skill families. All prior 5,749 records, including all 4,800 Math candidates, remain unchanged. The resulting inventory is 993 English and 4,800 Math candidates.

## Task and method coverage
| Skill | New task mechanism |
| --- | --- |
| Central Ideas and Details | Revise an interpretation without overstating the revised claim |
| Textual Evidence | Distinguish a proposed effect from an explicit confounder |
| Quantitative Evidence | Compare absolute between-group mean gaps across conditions |
| Inferences | Separate necessary requirements from sufficient guarantees |
| Words in Context | Resolve familiar words through the surrounding action |
| Text Structure and Purpose | Explain a concession’s role in a qualified proposal |
| Cross-Text Connections | Distinguish shared observations from competing evaluation criteria |
| Rhetorical Synthesis | Address an audience’s stated prior knowledge and goal |
| Transitions | Connect an expectation to a contrary observed outcome |
| Boundaries | Separate independent clauses around conjunctive adverbs |
| Form, Structure, and Sense | Attach an introductory modifier to its actual performer |

Each family owns a stable disjoint four-seed slot. A seed selects one explicitly authored context and reproducible choice order; arbitrary extra seeds do not manufacture more questions. Methods/formulas are instructional heuristics, not SAT scoring formulas. Difficulty labels are provisional.

Research settings, measurements, names and literary scenes are original hypothetical stimuli, not purported citations to real studies. No official or competitor passage, options or explanation was reconstructed. The [College Board public stem guide](https://satsuite.collegeboard.org/practice/student-question-bank/reading-writing) informs task categories only. The dated [College Board/OnePrep comparison](WEBSITE_DIRECTION.md) separates public descriptions from tested local preview behavior; no superiority claim is made.

## Review and integrity
The batch manifest records actual IDs, families, skill counts and observed answer positions. The pending pack at content/reviewed/english-application.md is for editorial inspection, not a published release. Each item has three explained distractors, two reasoning steps, exact evidence spans, provenance, family/seed metadata and uncalibrated status. No reviewer or approval is invented.

Direct contracts check all 44 contexts, explicit table values/gaps, confounder controls, modifier subjects, clause punctuation, deterministic replay and full-record preservation. Browser checks exercise server-only keys/methods, every correct choice and all 132 distractors, plus desktop/mobile tables, paired texts, notes and long choices. These tests establish implementation contracts, not independent educational validity.

The earlier 20,000-question expansion remains deferred. Human editorial review, broader independent context diversity and empirical validation remain necessary before publication or score claims.
